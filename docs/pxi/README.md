# pxi documentation

pxi is a review IDE for parallel coding agents: several Claude Code sessions, each in
its own git worktree, read and shipped from one native Mac window. These pages cover
what pxi adds. The editor, search, git and pull-request engine underneath is px0's,
documented in [../README.md](../README.md).

|---|---|
| [Getting started](getting-started.md) | Install, open a folder, the layout, first review |
| [Worktrees](worktrees.md) | Every worktree in one view, overlaps, new worktree with Claude, Ship, hide and delete |
| [Reviewing agent changes](review.md) | Diffs, viewed files, review checkpoint, walkthrough, review → agent |
| [Claude in pxi](claude.md) | Claude sessions, Threads with headless Claude, accounts, notifications |
| [Remote (SSH)](remote-ssh.md) | Browse and read files on another machine |
| [Shortcuts](shortcuts.md) | Every key pxi adds, and the main px0 ones |
