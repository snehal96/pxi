# Shortcuts

`⌘` is Cmd, `⌥` Option, `⌃` Control, `⇧` Shift.

## Added by pxi

| Keys | Action |
|---|---|
| `⌘O` | Open folder |
| `⌘⇧N` / `⌘T` | New window / new tab |
| `⌘⇧H` | Back to the workbench |
| `⌘Esc` | Show or hide the Claude tab |
| `⌥K` | Send the selected lines to Claude with a comment |
| `⌃\`` / `⌃⇧\`` | Toggle the terminal / open another one |
| `⌥⌘R` | Reload window |
| `⇧⌥⌘R` | Restart pxi |
| `⌘=` / `⌘-` / `⌘0` | Zoom |

## Commands (`⌘⇧P`)

| Command | Action |
|---|---|
| Review: Set Checkpoint / Clear Checkpoint | [Review checkpoint](review.md#review-checkpoint) |
| Preferences: Theme Follows macOS Light/Dark | Switch between pxi-light and pxi-dark with the system |
| Developer: Reload Window / Restart pxi | Reload the page / restart the app and its server |

## From px0

| Keys | Action |
|---|---|
| `⌘P` | Quick Open (current and recent files first) |
| `⌘⇧F` | Search in files |
| `⌘F` / `⌘G` | Find in file / go to line |
| `⌘E` / `⌘S` | Edit / save |
| `⌘D` | Toggle diff |
| `[c` `]c` / `[f` `]f` | Previous / next change block, changed file |
| `F12` / `⇧F12` / `⌥⇧H` | Definition / references / calls |
| `⌥T` | Threads |
| `⌥M` | Markdown or table preview |
| `?` | All shortcuts |
